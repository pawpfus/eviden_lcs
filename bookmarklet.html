🔖 Pintasan “Ambil Konten LCS”

Otomatis menyalin daftar konten dari dev.epusluh.id/lcs/list langsung ke aplikasi Eviden LCS.

LANGKAH 1 — Pasang pintasan (sekali saja)

Tampilkan bilah bookmark (Ctrl+Shift+B), lalu seret tombol di bawah ke bilah bookmark Anda:

📥 Ambil Konten LCS

Tidak bisa diseret? Klik kanan tombol → Bookmark this link / Tambahkan ke bookmark.

LANGKAH 2 — Pakai
  1. Buka dev.epusluh.id/lcs/list dan pastikan sudah login.
  2. Klik bookmark “Ambil Konten LCS”.
  3. Aplikasi Eviden LCS terbuka di tab baru dengan konten halaman itu sudah otomatis terisi sebagai baris.
  4. Tinggal lengkapi eviden (Like/Comment/Share) dan ekspor PDF/Excel.

Jika ada beberapa halaman (1, 2, 3 …), klik pintasannya di tiap halaman — barisnya akan ditambahkan, bukan menimpa.

Tidak otomatis terisi?

Buka aplikasinya sekali lalu refresh (agar versi terbaru termuat), kemudian ulangi Langkah 2.
